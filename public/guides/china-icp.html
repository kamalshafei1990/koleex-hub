1

Aliyun account + enterprise verification阿里云账号与企业实名认证

≈ 1 day (verification review up to 24h) · 约1天（认证审核最长24小时）

⚠️ Critical 关键提醒

Use the MAINLAND console aliyun.com — NOT the international alibabacloud.com. Only mainland accounts can do ICP filing.

必须使用中国站 aliyun.com，不要使用国际站 alibabacloud.com——只有中国站账号才能提交ICP备案。

1.1 Create the account 注册账号

Go to aliyun.com → 免费注册 (Register). Register with the company email + the Chinese mobile number.

打开 aliyun.com → 点击【免费注册】，使用公司邮箱和中国大陆手机号注册。

1.2 Enterprise real-name verification 企业实名认证

Console → account center → 实名认证 → choose 企业认证 (Enterprise). Upload the business license; verify the legal representative with passport. If bank-transfer verification is offered and difficult, choose the legal-rep verification path (法人认证) via the Aliyun app.

控制台 → 账号中心 → 【实名认证】→ 选择【企业认证】。上传营业执照；法定代表人用护照完成认证。如对公打款不方便，选择【法人认证】通过阿里云APP完成。

2

Register the 3 domains注册三个域名

≈ 30 minutes + up to 1 day for domain real-name review · 约30分钟＋域名实名审核最长1天

2.1 Buy 购买

Go to wanwang.aliyun.com (万网). Search and add ALL THREE to cart: koleexgroup.cn (register 3 years + auto-renew 自动续费 ON), koleex.cn (1 year), koleexhub.cn (1 year). Owner type = 企业 (Enterprise), owner = the Taizhou company.

打开 wanwang.aliyun.com，搜索并将三个域名加入购物车：koleexgroup.cn（注册3年并开启【自动续费】）、koleex.cn（1年）、koleexhub.cn（1年）。所有者类型选【企业】，填写台州公司信息。

2.2 Domain real-name 域名实名认证

Console → 域名 (Domains) → each domain → 实名认证: submit the company's business license as the registrant. Status must become 已实名 before ICP filing.

控制台 → 【域名】→ 逐个域名提交【实名认证】（使用公司营业执照）。状态变为【已实名】后才能提交备案。

⚠️ Parking rule 备用域名规则

koleex.cn and koleexhub.cn are protective only: do NOT add any DNS records, do NOT point them anywhere, and they need NO filing while unused.

koleex.cn 和 koleexhub.cn 仅作品牌保护：不要添加任何DNS解析，不指向任何网站；不使用则无需备案。

3

Light server → filing service code轻量应用服务器与备案服务码

≈ 20 minutes · 约20分钟 — the server itself will not host anything 该服务器不实际托管任何内容

3.1 Buy the cheapest light server 购买最低配轻量服务器

Console → 轻量应用服务器 (Simple Application Server) → cheapest plan, region 华东 (East China), duration 3 months (the minimum that grants filing codes).

控制台 → 【轻量应用服务器】→ 选择最低配置，地域选【华东】，购买时长3个月（申请备案服务码的最低要求）。

3.2 Get the filing service code 申请备案服务码

In the server's console page → 备案 (Filing) → apply for a 备案服务码 (filing service code). Copy it — Phase 4 needs it.

在服务器控制台页面 → 【备案】→ 申请【备案服务码】，复制保存，备案时需要填写。

4

Submit the ICP filing提交ICP备案

Form ≈ 1 hour; review 1–3 weeks · 填表约1小时；审核1–3周

4.1 Start 开始

Go to beian.aliyun.com → 开始备案 → type = 首次备案 (first filing). Subject 主体 = the Taizhou company; fill legal-rep info exactly as the passport.

打开 beian.aliyun.com → 【开始备案】→ 选择【首次备案】。主体填写台州公司；法定代表人信息与护照完全一致。

4.2 Website info 网站信息

Domain = koleexgroup.cn. Website name 网站名称 = 科莱恪斯内部管理系统 (internal management system). Purpose 服务内容 = 单位门户/内部办公 (company portal / internal office). Attach the 备案服务码 from Phase 3. Avoid any commercial/news/finance wording — those trigger extra pre-approvals.

域名填 koleexgroup.cn；网站名称填【科莱恪斯内部管理系统】；服务内容选【单位门户/内部办公】；填入第三阶段获取的备案服务码。切勿使用金融、新闻、电商等字样，避免触发前置审批。

4.3 Verification 核验

Upload documents, then complete face verification 人脸核验 for the legal rep inside the Aliyun app. Submit.

上传材料后，法定代表人在阿里云APP内完成【人脸核验】，然后提交。

⚠️ During review — three hard rules 审核期间三条铁律

1. The domain must NOT resolve to anything — add no DNS records until approval. 2. Answer every call from Aliyun/MIIT reviewers (they verify by phone). 3. When the MIIT SMS arrives (工信部短信核验), complete the link within 24 hours or the filing is rejected.

1. 审核期间域名不得解析（不要添加任何DNS记录）。2. 务必接听阿里云及管局的核验电话。3. 收到工信部短信核验后，须在24小时内完成，逾期将被驳回。

✅ Done when 完成标志

You receive the filing number like 浙ICP备2026XXXXXX号. Send it to Kamal / the assistant immediately.

收到备案号（如 浙ICP备2026XXXXXX号）即为通过，请立即发给Kamal／系统助手。
