## 4. ⭐ The symbols page is a field dictionary — the most reusable thing in the file

The last spread prints **40 icons with Chinese + English labels**, which is the exact
vocabulary the icon-bar sheets encode. It resolves the problem that made S-001's
overlock and coverstitch bars unreadable:

> Flat type · Raised Flat-Bed · Box Type · Application · Needle · No. of Needles ·
> No. of Threads · **Needle Gauge** · Stitch Length · **Needle bar stroke** · Auto
> trimmer · **Differential ratio** · Light / Medium / Heavy Materials · Bottom Feed ·
> Needle Feed · **Comprehensive feed** · Top-and-bottom feed · Stitch Width · Thread
> wiper · **Stitch width (swing)** · Horizontal Hook (standard) · Horizontal Hook
> (Large) · Vertical Hook (standard) · Vertical Hook (Large) · **Shuttle hook** ·
> Cutter size · Button holing size (horizontal) · Button holing size (round) · Button
> stitch · Button Diameter · Power · Bartacking · Presser foot lift · Sewing speed ·
> Weight NW/GW · Packing size

Two facet notes fall straight out of it:
- **"Comprehensive feed" is this catalogue's English for 综合送料 = compound/unison
  feed** — our `feed_type: compound-unison`. Do not mint a new value for it.
- It distinguishes **stitch width** (针迹宽度) from **swing width** (摆幅). Zigzag bight
  is the second one. Reading the first as bight would be wrong by definition.

## 5. Facet evidence — and it repeats the CL-0020 lesson

- **`bed_type: post` dominates.** Three separate series are post-bed, with column height
  as a *dimension*, not a type: 180 / 303 / 320 / 420 / 443 / 550 / 703 mm.
- **`feed_type: roller`** (added 2026-08-14) is confirmed by a ~20-model series — the
  largest roller evidence in the library.
- **`bed_type: bending-arm`** confirmed again by **SR-1568 curved-arm zigzag**.
- ⚠️ **SR-1588D is a POST-BED ZIGZAG and SR-2312D is a CYLINDER ZIGZAG.** Same bed
  shapes as the lockstitch series above, different stitch class — **the third
  independent confirmation that bed shape can only ever be a facet, never a
  subcategory** (CL-0020, restated in CL-0023).
- **SR-8630 / 8640 / 8640B are "360° rotating"** and **SR-8368 is a "rocking arm"** —
  neither is in the bed dictionary. Recorded as **observations, not proposed values**:
  one catalogue is not a vocabulary.

## 6. Traps

1. **`pdftotext` gives nothing.** Render it. Anyone searching the library by keyword
   will conclude this catalogue does not mention shoes.
2. **Two files, one supplier.** `Goldsew (金梭).pdf` also exists and is also image-only.
   They have not been compared; a model in one is not evidence of absence in the other.
3. **SR-01 … SR-24 have no names at all** — two spreads of bare photographs with code
   labels. Twenty-four machines that cannot be classified from this file.
4. **SR-298B glues and folds; it does not bind.** `XSEE` is Edge *Binding*. Filing it
   there to fill an empty shelf would break what the code means — the same error
   avoided when `XSEK` was minted rather than reusing `XSEE`.
5. **The SR-168 sheet covers three models and the bag variants share the family**, so
   the bag machines' own weights and dimensions are **not printed**. Do not copy the
   shoe figures across.
